# artemkagoldman.github.io

My page: **[artemkagoldman.github.io/support](https://artemkagoldman.github.io/support/)** — the ways to
support the free, open-source apps I make, in one place. Every app's "Support the developer" button
opens it, so a new way to donate or a new project only needs this page changed, never an app.

- `support/index.html` — the page. The donation options and the projects are two lists at the top of
  its script: a way to donate shows once it has a link, and a project is one more entry.
- `index.html` — sends the bare address to the support page, until there is a home page.

Plain HTML, CSS and a little JavaScript, served by GitHub Pages as is. Icons are [Lucide](https://lucide.dev)
(ISC licence), the same set the apps use. No build, no trackers, no
cookies.
